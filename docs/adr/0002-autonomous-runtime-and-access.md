# ADR-0002：通用 root Agent 执行、自主工具获取与全局密钥入口

日期：2026-10-08（Asia/Shanghai）

状态：历史决策，部分被 [ADR-0004](./0004-tool-lifecycle-runtime-and-observability.md) 替代；默认 root 已改为普通用户与有限按需提权，自主研究与全局密钥原则保留。

历史沿革：[ADR-0003](./0003-single-host-stack-and-tool-design.md) 曾采用 app 与 Runner、SQLite；这些部署/数据库选择与本文默认 root 均已失效。当前为 [ADR-0005](./0005-compose-kali-tool-retention-and-development.md) 的三常驻服务，以及普通用户执行、隔离准备阶段按需 root。自主联网研究与全局密钥原则保留；Broker 表示获取职责，不要求独立常驻容器。

## 背景

用户希望 Agent 自己判断是否连接和测试 Redis 等服务，而不是必须先开发每种协议的适配器；同时要求自主联网搜集 CVE、PoC、EXP 和利用工具、安装与扩充工具，以 root 操作容器，并用全局密钥保护 Web 主页。

此前以专用工具适配器为主、动态安装后置、工具容器默认非 root 的设计不足以表达这种自主性。本次按新需求修改总纲，不将旧文档的限制作为阻止调整的依据。

## 决定

| 事项 | 新基线 |
| --- | --- |
| 协议 | 通用 Shell、TCP/TLS 工具与客户端库提供连接能力；Agent 根据证据决定研究路径；专用适配器只作可选增强 |
| Redis | 首批非 Web 验收样例，不要求开发 `check_redis_access` 才能进行研究 |
| Root | Agent 可见的会话默认真实 UID 0，可执行 Shell、安装、编译、修改容器文件和运行脚本；平台进程及宿主权限另行隔离 |
| 执行环境 | 每个研究会话保留独立目标容器及环境记录；联网安装在洁净准备容器完成，版本化制品导入目标容器 |
| 联网 | 首版包含自主搜索公告/CVE/PoC/EXP/工具、分析适用性、下载、安装和执行；检索/获取来源由受控 Broker 提供 |
| 工具 | 固定版本的预装基础工具可通过镜像配置扩充；会话工具可自主扩充，不要求每个工具有专用 API 包装 |
| 审批 | 已授权的检索、安装和验证自动推进；出现超出范围、宿主能力或既有动作权限的需求时才申请具体补充计划 |
| Web 访问 | 一个全局高熵密钥在服务端验证后换取会话；主页、业务静态资源、API、流、配置、报告和证据统一保护 |

不向工具容器开放 Docker socket、任意宿主挂载、host 网络或 privileged 模式。容器内 root 与全部宿主权限不同，必要 capabilities 经运行验收后配置。[Docker 运行权限](https://docs.docker.com/engine/containers/run/#runtime-privilege-and-linux-capabilities)

## 技术取舍

通用 Shell 保留探索自由，也意味着不能再声称命令 Schema 或正则过滤可以严格保证每个脚本的全部行为。网络范围与进程/资源边界在容器外执行；需要更严格限制目标侧操作时，使用不开放通用 Shell 的 `restricted-tools` 模式。自主模式仍按既有授权运行，并记录计划、源码、版本和实际结果。

允许会话修改文件和安装依赖，需要从“每个调用一个干净只读容器”调整为“会话保留环境，调用独立留痕”。接触目标数据的环境不能再直接切回公网安装环境；缺少依赖时，Agent 在新的洁净准备容器中补齐，再导入制品。共享缓存不接受会话直接覆盖，Reviewer 使用独立重建环境。

包安装本身可能执行外部代码，来源记录、hash 和自动代码分析不能证明它无害；它们提供可追溯性，隔离边界仍由执行环境承担。工具 stdout 也不能独立证明漏洞成立，关键结果需要原始交互或独立复现支持。

全局密钥简化首版部署，但所有持有者共享权限。会话可撤销、密钥可轮换，不能只在 Vue 路由中比较一个前端可见字符串。认证设计采用服务端会话、HTTPS Cookie、CSRF、限速和输出净化。[OWASP 会话管理](https://cheatsheetseries.owasp.org/cheatsheets/Session_Management_Cheat_Sheet.html)

## 验收与迁移

以下为 0.3 当时的验收记录，不是当前要求：root Shell 可用；自主获取和安装一个未预装工具；无需协议专用适配器完成非 Web 样例；目标与下载出口分离；未知副作用可恢复处理；无有效密钥会话无法绕过入口访问业务数据；退出/轮换/到期与实时流一致失效。当前验收统一查阅根目录 `PROJECT.md`，不继续实现默认 root Shell。

更新 `PROJECT.md` 至 0.3，同时更新 `README.md` 与 `AGENTS.md`。当前只有文档，无运行中的容器、登录模块或数据库可迁移；本次未实际安装利用工具、抓取 PoC、生成真实访问密钥或发起目标测试。
