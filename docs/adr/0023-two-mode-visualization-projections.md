# ADR-0023：双模式下的研究过程可视化投影

日期：2026-10-10。状态：已采纳，待实施。扩展 [ADR-0015](./0015-graph-semantics-and-projection-boundary.md)，细化 [0007 工作台规格](../specs/0007-research-workbench-ui.md) 的视图集合。决策依据见 [2026-10-10 双模式架构评估](../research/2026-10-10-two-mode-architecture.md)。

可视化层**不因模式重新设计**：总纲第 12.1 节的七个可观察视图、ADR-0015 的只读投影与水位语义、0007 的工作台骨架与状态视觉编码表继续有效。本决定只补模式带来的新增投影。

## 新增三个投影

| 投影 | 属于 | 解决的问题 |
| --- | --- | --- |
| 覆盖矩阵 | coverage | 0007 的"服务组 / 分支泳道"是为单 Run 少量服务设计的；几千资产 × 几十检查项会不可读。coverage 的问题是"还有什么没测、为什么没测"，0007 状态栏的"未覆盖 N / 受阻 N"两个计数不足以表达"缺能力"这类缺口 |
| 攻陷状态 | breach | `Identity / Access / FootholdSession / TrustEdge` 不属于既有的服务事实关系与研究血缘关系两类，而这一类最需要可视化 |
| 缺口视图 | 两者 | 按资产重要性、协议与原因拆分 capability_gap，并显示首次触达 / 部分覆盖 / 完全未触达 |

**不新建第二份研究状态，不引入图数据库**：新增视角是同一套只读投影的扩展，共用同一水位、快照与 keyset 分页协议。投影按模式切换，但机制只有一套。

## 明确不做的

- 画布不作为执行依据，不从画布推导模型上下文。
- 画布上的凭据可用边不授权尝试；跨主机动作仍须逐目标/端口/动作校验（[0007 §3](../specs/0007-research-workbench-ui.md)）。
- 聚合视图不能替代逐项事实：一台资产的实证不能确认其余入口，每个入口保留独立证据、条件与判定。
- 覆盖分母注明登记依据与版本，沿用既有 `total_basis=exact / estimate / unknown` 口径，分母未知不显示覆盖百分比；服务发现失败的资产不能因为没有生成检查项就消失在分母外。

## 后果

- 0007 的状态视觉编码表需要补 breach 相关行（能力已证实/未证实、会话存活/已终止/停止未确认、凭据已记录/已使用/已失效），并保持"必须显示 / 不得暗示"两列。
- P2-F 的验收范围当前只覆盖少量服务的可读性；**几千资产规模下的矩阵渲染、下钻与查询容量需要新增验收项**。
- 聚合下钻与覆盖分母的口径引用既有规定，不重复定义。
- 本决定不表示任何图投影、投影服务或可视化页面已经实现。
