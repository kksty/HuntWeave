# ADR-0012：默认最小实证与目标数据保护

日期：2026-10-09。状态：按用户明确要求采纳，待实现。产品规则见 [PROJECT §9.1](../../PROJECT.md)，行为与验收见 [P2 规格 §6](../specs/0003-agent-research.md)。

已授权 Run 默认包含 RCE 等较高影响漏洞的最小实证，不再以严重性或漏洞类别要求额外许可。RCE 成功后仅只读采集身份、主机与时间证据并退出，绑定实际目标和受信执行记录；成功不成为进一步控制、读取业务数据、提权或驻留的起点。用户明确配置的更窄限制仍生效，目标、有效期、预算与执行隔离仍须满足。

选择以实际影响约束自主验证，而不是按漏洞名称逐类批准。禁止破坏、删除或修改目标已有数据/配置；确实不可避免的独立测试新增数据按最低必要量执行并记录，尤其大量脏数据必须醒目披露。报告说明不能使破坏性操作合法化，Agent 也不得以清理为由删除/修改目标数据；遗留交由操作员处理。

## 替代与后果

- 替代 PROJECT 0.8.4 中「RCE 等较高影响漏洞的验证仅在明确允许的验证策略/具体计划内执行」的额外类别门槛（该门槛已由 0.9.1 按本决定替换），并补足一般数据写入与清理的描述；不扩大任何实际目标的授权范围。
- 默认验证策略在创建 Run 时展示并固化，旧授权快照不静默放宽；显式限制继续执行。通用 Shell 的工程局限仍需如实说明，命令名、路径规则或 LLM 不能被称为完整副作用证明。
- P1 真实执行计划已需遵守非破坏边界；自主 RCE、测试新增数据记账与版本化报告随 P2 交付。此次只修改文档，不表示功能已实现，也不发起任何目标测试。
