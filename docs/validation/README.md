## 记录约定

- 新增记录命名为 `NNNN-主题.md`，按序号追加，不覆盖已有记录；如有更正，在记录内新增「本记录的更正」一节，而不是改写原始结论。
- 每条记录包含：环境与入口、行为与结果、未达成与限制、（适用时）待人工确认。计数与 hash 写实际值，不写「全部通过」这类无法复核的表述。
- 验收只用 `lab/` 自建靶场与文档保留 IP，不连接任何外部目标；故障注入只作用于显式的一次性项目（`deploy/verify_*.py` 拒绝其他项目名）。
- 浏览器截图写入被忽略的 `runtime/validation/`；记录里引用其路径，不把二进制提交进仓库。
- 记录完成后回接两处：[`../STATUS.md`](../STATUS.md) 的对应阶段与下一实施项，以及 [README 的项目资料](../../README.md#项目资料)。
