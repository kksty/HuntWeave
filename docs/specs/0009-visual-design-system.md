# 0009：视觉设计系统（NASA-punk 设备面板）

状态：设计已确定，待实施。决定与取舍见 [ADR-0024](../adr/0024-nasa-punk-visual-language.md)；工作台结构与交互见 [0007](./0007-research-workbench-ui.md)；状态语义见 [0006](./0006-state-model-and-delivery.md) 与 [0005](./0005-capability-claim-criteria.md)。

## 1. 目标与适用范围

风格定位是**像一台真实的航天设备**：70 年代 NASA 规范手册的工程制图语言加浅色数据界面，读起来像仪表与铭牌，而不是终端或营销页。

适用于全部业务页面、登录页、证据查看页与后续新增的模式界面。**不适用于**导出的报告与验证记录文档——它们沿用同一色板即可，不受面板、接缝与铆钉约束。

## 2. 三条总则（来自既有约束，不是审美偏好）

1. **颜色不承载状态。** 状态由文字、图标、位置与编号表达；移除全部颜色后状态仍可辨识（[0007 §6](./0007-research-workbench-ui.md) 的成对验证）。
2. **装饰不得伪造语义。** 任何编号、方向标注与警示图案都必须绑定真实对象或真实含义；禁止编造无意义的编号与假警示。
3. **使用痕迹必须确定。** 静态资源或固定 seed，禁止每次渲染随机。

## 3. 色板与 token

必须先建立 token 层，禁止在组件内写死色值。token 层落在 `frontend/src/tokens.css`，是**唯一色值来源**；字体族名、字阶与间距也在同一文件里。机械检查入口为 `frontend/scripts/check-design-system.mjs`（`npm run check:design`），它扫描源码与构建产物，证明没有 token 层之外的色值、中文不会落到 Latin 等宽、以及构建产物里没有商业字体文件。

| token | 值 | 允许用途 | 禁止用途 |
| --- | --- | --- | --- |
| `--hw-base` | `#ECE5D6` | 页面底色 | — |
| `--hw-panel` | `#F6F2E9` | 面板面、页眉面 | 页面底色 |
| `--hw-ink` | `#1E1B16` | 正文与细线文字；一级与次级文字都用它，层级靠字号与字重表达 | — |
| `--hw-line` | `#8A7F6B` | 分隔线、接缝、表格线、控件描边 | 状态编码；正文文字 |
| `--hw-accent` | `#D63A2C` | **唯一鲜艳强调色**：主操作、当前项标记、关键计数、键盘焦点环 | 状态编码；正文小字（对底色实测 3.72:1，对面板面 4.18:1，均低于 4.5:1） |
| `--hw-accent-ink` | `#A8432F` | 需要小字号红字时（对底色实测 4.77:1，对面板面 5.36:1） | 大面积填充 |
| `--hw-stripe-1..4` | `#4C5A68` / `#7A7F4E` / `#D2A85E` / `#A8432F` | 身份条与任务徽章 | 文字、状态、小图标 |
| `--hw-hazard` | `#1E1B16` 与 `#ECE5D6` 斜纹 | 阻断、危险操作、越界确认 | 装饰性分隔、常规面板 |

每个面板内 `--hw-accent` 的使用点不超过一个（主操作或当前标记），这是"只用最重要的按钮或标记"的可检查形式。

### 对比度实测（V-A / issue #33）

原型里的 `--hw-panel`、`--hw-ink`、`--hw-line` 只写"建议"。V-A 实测后**确认 `--hw-panel` 与 `--hw-ink`、收紧 `--hw-line`**：原建议值 `#B9AF9C` 对底色只有 1.73:1、对面板面 1.94:1，达不到非文本对比度下限，换成 `#8A7F6B`。

计算方法：WCAG 2.x 相对亮度与对比度公式。对每个 8 位 `RRGGBB` 通道 `c ∈ {R,G,B}`，先归一化 `s = c/255`，再用 `f(s) = s/12.92`（当 `s ≤ 0.04045`）或 `f(s) = ((s+0.055)/1.055)^2.4`（否则）得到线性值；相对亮度 `L = 0.2126·f(R) + 0.7152·f(G) + 0.0722·f(B)`；对比度 `CR = (L_亮 + 0.05)/(L_暗 + 0.05)`。公式自检：`#FFFFFF` 对 `#000000` 得 21.0000，与定义一致。

取整口径：保留 4 位小数用于存放，文档与验收判定统一写**四舍五入到 2 位小数**并带 `:1` 后缀。判定阈值用 WCAG 2.x：正文小字号文字 ≥ 4.5:1，大字号文字（≥ 24px 常规或 ≥ 18.66px 粗体）与图标/边框一类的非文本部件 ≥ 3:1。

| 前景 | 背景 | 实测（4 位小数） | 文档口径（2 位） | 判定 |
| --- | --- | --- | --- | --- |
| `#D63A2C` `--hw-accent` | `#ECE5D6` `--hw-base` | 3.7205 | 3.72:1 | 只可用于大字号与非文本（3:1 达标，4.5:1 未达） |
| `#D63A2C` `--hw-accent` | `#F6F2E9` `--hw-panel` | 4.1761 | 4.18:1 | 同上；即使落在面板面上也不足 4.5:1 |
| `#A8432F` `--hw-accent-ink` | `#ECE5D6` `--hw-base` | 4.7723 | 4.77:1 | 小字号红字可用 |
| `#A8432F` `--hw-accent-ink` | `#F6F2E9` `--hw-panel` | 5.3567 | 5.36:1 | 小字号红字可用 |
| `#1E1B16` `--hw-ink` | `#ECE5D6` `--hw-base` | 13.6857 | 13.69:1 | 正文可用 |
| `#1E1B16` `--hw-ink` | `#F6F2E9` `--hw-panel` | 15.3617 | 15.36:1 | 正文可用 |
| `#8A7F6B` `--hw-line` | `#ECE5D6` `--hw-base` | 3.1425 | 3.14:1 | 非文本部件可用（≥ 3:1） |
| `#8A7F6B` `--hw-line` | `#F6F2E9` `--hw-panel` | 3.5273 | 3.53:1 | 同上 |
| `#F6F2E9` `--hw-panel` | `#ECE5D6` `--hw-base` | 1.1225 | 1.12:1 | 面与页底的分层；接缝由 `--hw-line` 的 1px 细线给出，不靠面色差 |

结论对用途的支持关系：

- `--hw-accent` 的允许用途（主操作底、当前项标记、关键计数、焦点环）全部按**非文本或大字号**处理，实测 3.72:1 / 4.18:1 支持这一用途；禁止用途（正文小字）也被实测值否掉，条文与数据一致。
- `--hw-accent-ink` 的允许用途（小字号红字：错误提示、无效标记）实测 4.77:1 / 5.36:1，支持该用途。
- `--hw-line` 只用于非文本部件，实测 3.14:1 / 3.53:1 支持该用途；它被明确禁止用于正文文字。
- `--hw-stripe-1..4` 是身份元素，不承载文字、状态与小图标，因此不要求文字对比度；它们与文字的搭配一律使用 `--hw-ink`。
- `--hw-panel` 与 `--hw-base` 的 1.12:1 不足以单独区分面与页底，因此面板边界必须同时有 `--hw-line` 的 1px 细线（§5）。

V-A（issue #33）执行这条硬约束，并顺带把 `frontend/src/style.css` 里原本写死的 18 个色值全部换成语义槽位；逐值映射表见 [验证记录 0021](../validation/0021-visual-tokens.md)。

## 4. 字体与中文排版

| 用途 | 字体 | 许可 |
| --- | --- | --- |
| 标题、面板标签（加宽无衬线） | Archivo Expanded | OFL |
| 正文 | IBM Plex Sans 或 Sarasa Gothic SC | OFL |
| 编号、ID、hash、计数、命令输出（等宽） | IBM Plex Mono | OFL |
| 中文正文 / 中文等宽 | Sarasa Gothic SC / Sarasa Mono SC | OFL |

规则：

- **中文不得交给 Latin 等宽字体 fallback 渲染**。数字与编号走等宽，中文走中文字族，混排时按行内组合处理。V-A（issue #33）把这个规则做成机制而不是纪律：`frontend/src/fonts.css` 里 Sarasa Gothic SC 与 Sarasa Mono SC 的 `@font-face` 用 `unicode-range` **只声明汉字与中文标点**，Latin 字母、数字与编号不在其中，因此它们只能落到 IBM Plex；字体栈顺序为 `--hw-font-sans: 'IBM Plex Sans', 'Sarasa Gothic SC', …`、`--hw-font-mono: 'IBM Plex Mono', 'Sarasa Mono SC', …`。中文字体按「前端源码与产品文档里真实出现的汉字与中文标点」子集化（完整 TTF 各 23–25MB，子集后每个字重约 242KB），字符集由 `frontend/scripts/build-fonts.mjs` 唯一决定，可复现；检查脚本逐字核对前端用到的中文字符都在中文字族的 `unicode-range` 与字体 cmap 内。
- 全大写只用于 Latin 标签与编号；**中文不做全大写效果**。
- Univers Extended 与 Helvetica 是商业字体，**仓库不得打包其字体文件**；只能作为字体栈尾部的本机回退，默认交付一律使用上表的 OFL 字体并自托管。V-A 的实际交付是 5 个 OFL 字族、9 个 woff2、合计 1,162,192 字节，随资产附 3 份 OFL 许可文本，`npm run check:design` 会核对仓库与 `frontend/dist` 里没有商业字体文件，且默认字体栈里不出现商业字体名。

## 5. 面板与结构

- 1px 细线分隔，**留出可见接缝**；面板直角（圆角 0，最多 2px）。
- 铆钉与紧固件是静态 SVG，只出现在面板四角或接缝端点，**不作为可点击元素**。
- 间距按 8px 基准栅格。
- 禁止大面积渐变；允许不超过 1px 的内阴影表达"嵌入面"。

## 6. 功能图案与标签

- **黑白警示斜纹**只用于阻断、危险操作与越界确认。它承载"停下来看"的含义，用在别处会让真正需要停下的信号失效。
- **方向与编号标注**（`STOW 84S`、`THIS SIDE UP` 一类）必须绑定真实语义：分区编号用真实面板 ID，编号用真实 Run／调用短码或真实计数。**禁止装饰性假编号**。
- 标签统一为全大写、小字号、加宽字距；中文标签不套用全大写。

## 7. 身份元素

- 四色复古条只出现在页眉身份带与徽章，不作为进度、状态或数据可视化的一部分。
- **任务徽章表达身份，不表达状态。** 它在真实航天语境里标识的是"哪次任务"而不是任务处于什么状态，因此对应到产品就是标识 `Project`：**形制与四色顺序由 `Project` 固定**，同一项目下所有 Run 的徽章一致。
- 徽章内是**真实文字**：Run 短码与真实计数（资产数、确认级发现数）。**不得出现状态色块、进度环、百分比，或任何随状态变化的图形**；**不得由 Run 标识派生图案**（看起来有信息而实际没有，且不同图案会被误读成分类）。
- 徽章是静态 SVG，**不做图案生成算法**；它本身不是交互目标，需要跳转时在徽章旁提供真实链接；必须有 `aria-label` 说明它是项目身份标识。
- 判断标准：一个元素删掉后操作员不会失去任何可执行信息时，它只能是身份标识，**不能长得像状态指示器**。

## 8. 使用痕迹

- 轻微划痕、贴纸、手写提醒：静态资源、固定位置、固定 seed。
- **不得叠在文字、状态、按钮与证据内容上**，不得降低任何可读性。
- 不做动画，不允许"脏到看不清"。

## 9. 明确禁止

霓虹发光、全息投影、大面积渐变、暗色赛博风格、玻璃拟态、彩色状态灯、假编号、随机使用痕迹。

## 10. 与既有约束的关系

- [0007 §6](./0007-research-workbench-ui.md) 的状态视觉编码表继续有效；本系统只为它提供色彩与字体承载，**不改变任何状态语义**。
- 单一健康灯继续禁止；执行／研究／复审／交付并列显示的要求不变。
- 证据原文与命令输出区域**不加装饰**，可读性优先于风格。
- 覆盖面与突破模式的新界面（模式标注、覆盖矩阵、缺口视图、攻陷状态）按本系统实现，不另立风格。

## 11. 验收

1. 移除全部颜色后，各状态仍可辨识（灰度截图检查）。
2. 每个面板内 `--hw-accent` 使用点不超过一个。
3. `#D63A2C` 不用于正文小字；小字号红字使用更深的 `#A8432F` 或更深值。
4. 四色条不承载文字、状态或数据；徽章只承载真实身份标识与真实计数，**不含状态色块、进度环或百分比**；同一 `Project` 下不同 Run 的徽章形制与色序一致，仅文字数据不同。
5. 警示斜纹只出现在阻断、危险与越界路径上。
6. 机械检查：无大模糊 `box-shadow`、无多层 `radial-gradient`、无 neon 类关键字。
7. 使用痕迹为静态资源，不覆盖文字；**同一页面两次渲染像素一致**（视觉回归稳定）。
8. 中文由中文字体渲染，未落到 Latin 等宽 fallback。
9. 仓库与构建产物不含商业字体文件；字体全部为 OFL 或系统字体。
10. 换肤后既有 Playwright 用例通过，且视觉回归不 flaky。
