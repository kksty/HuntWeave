# P2-F：研究工作台与复审交互规格

状态：设计已确认，待实施、未验收。日期：2026-10-10。领域行为以 [0006 状态与交付](./0006-state-model-and-delivery.md)、[0005 判据](./0005-capability-claim-criteria.md)、[0004 准入](./0004-finding-admission.md) 为准；图边界以 [ADR-0015](../adr/0015-graph-semantics-and-projection-boundary.md) 为准。本文件定义信息架构、交互骨架和异常反馈，不是已经运行的界面或视觉成稿。

## 1. 使用目的与页面

操作员应能回答：研究到哪里、为什么等待、尝试了哪些方法、哪些主张有何依据、还缺什么、如何提交有效的下一步，以及当前与冻结交付有何区别。首版仍是全局密钥的服务端会话，不引入个人账号。

| 页面 | 主要内容与动作 |
| --- | --- |
| Run 列表 | 执行/研究/复审/交付四组摘要，目标数、预算、授权截止、投影滞后；进入运行或创建 |
| Run 创建 | 四步：IP 校验预览 → 端口/访问条件/授权说明与有效期限 → 深度偏好/预算及耗尽行为 → 实际硬约束摘要并发布 |
| Run 总览 | 所有状态分桶、覆盖范围、未覆盖/未决/结果未知/受阻常驻计数、IP 排队与隔离状态、未决输入需求、遗留清单 |
| IP / 服务工作台 | IP 组合图、服务与入口子图、尝试/证据详情、调用输出与增量时间线 |
| Attempt 详情 | 可从图或列表打开的同一业务记录，调用序列、实例重建、状态与证据；支持深链回到图中位置 |
| ReviewQueue | 确认等级、输入版本、缺口、独立意见、分歧、最久等待及背压；人工确认/退回/标记未决 |
| 当前发现与历史裁定 | 当前准入独立标识，退出原因及历史计数可见，评分与确认记录；不混淆候选与入库 |
| 冻结交付 | manifest 输入、图修订、范围/缺口/遗留、当前与冻结版本、有效期和保留期；生成新修订或导出 |

创建时非法 IP、重复项、超限和未验证 IPv6 能力明确反馈；错误行须修正或显式移除，不能静默忽略。授权期限不能为空，明确勾选已获授权；深度档位不表示授权时长，不承诺跑满 24 小时或完整覆盖。所有业务页面/API/SSE/证据均经服务端鉴权。

## 2. 工作台骨架

```text
┌ Run / 授权与预算面板 / 暂停·取消·恢复 ───────────────────────┐
│ 执行〔A3+A6〕  研究〔A1〕  复审〔A2〕  交付〔A4+冻结版本〕 │
│ 未覆盖 N · 未决 N · 结果未知 N · 受阻 N · 投影 X/Y          │
├────────────┬────────────────────────┬────────────────────┤
│ IP → 服务  │ 研究图：发布顺序 →      │ 选中对象详情       │
│ → 入口     │ 服务组 / 分支泳道      │ 事实·引用·限制     │
│ 队列原因   │ 视角 / 图例 / 筛选     │ 版本化业务动作     │
│ 隔离警示   │ 局部展开 / 列表替代    │                    │
├────────────┴────────────────────────┴────────────────────┤
│ 事件时间线：实际调用 / 转向 / 重建 / 核对 / 补拉状态         │
└─────────────────────────────────────────────────────────┘
```

默认按业务发布顺序、服务分组及组内分支泳道阅读研究过程；节点另列实际采集时间、持续时间和等待耗时。长等待折叠须标压缩，不把图上距离当真实时间。服务拓扑与 Run 依赖视角可切换；布局不改变业务关系，也不产生执行计划。

IP 是组合导航，服务/入口是研究锚点。多服务尝试各处引用同一 ID；非主锚点显示“引用”并能跳主位置，不复制状态、覆盖或费用。用 A 的条件验证 B 不使 A 自动成为已覆盖。多个合法尝试可以共用同一锚点。

## 3. 节点、关系与视觉编码

节点类型包括服务/入口、研究项、主张、尝试、观察/证据、前提门、复审与交付引用。Collector、准备和报告记录使用明确类型或独立泳道，不伪装为漏洞尝试。工具调用默认在尝试内展开，实例重建为可追溯徽章，普通重试不产生新研究节点。

关系使用程序校验的闭合词表；关系类别与可用于何种查询分别记录。计划依赖由已提交 Decision/前提记录证明其存在，不要求目标上的能力证明；能力支持/反驳关系须引用具体证据；复审与准入关系须引用相应评估记录。解释绑定具体片段或记录、随关系版本保存并视为不可信内容。未提交的模型关系建议以虚线区分，不自动进入结论路径。路径只能索引记录，不能替代 all_of/any_of 或硬约束检查。

每条关系独立表达：是否正式记录、目标能力是否已验证、结论是否已复审。旧关系经更正/撤回记录退出当前投影，保留历史。跨主机已记录关系可显示；邻域读取不授权探测，任何新的跨主机动作须逐目标/端口/动作校验。越范围线索不能通过展开按钮新增目标或调用。

| 状态 | 必须显示 | 不得暗示 |
| --- | --- | --- |
| `undetermined` | 未决、具体缺口 | 已失败或已排除 |
| `supported` | 已有支持、证据/判据/确认等级缺口分别列出 | 字段填齐即成立 |
| `refuted` | “该主张在所述条件下已被反驳”，条件/版本及反例链接 | 分支失败、服务安全或目标无风险 |
| 当前 `confirmed` | 在明确范围内按有效契约成立，确认等级、确认记录/程序或会话来源 | 入库、全目标安全、自然人身份已被认证 |
| `lapsed` | 曾有判定、必要依据失效、当前资格与重审需求 | 已被证伪或历史被删除 |
| `blocked` | 受研究前提阻断、缺什么、恢复条件 | 执行失败或结果未知 |
| `awaiting_model / awaiting_prep` | 等待类别、时长、原因，不占目标执行额度 | 主张等级降低 |
| ToolCall `unknown / incomplete` | 结果未知/结果不完整；独立停止事实 | 失败、成功或可盲目重试 |
| `stopped_unconfirmed` 展示态 | 停止未确认、最后实例/调用、占用及核对入口 | 已取消或额度已释放 |
| IP `quarantine / degraded` | 不可折叠的原因、停止/核对状态、恢复条件 | 仍可只读请求目标 |
| `admitted_current` | 独立准入标识、评分与全部决定版本 | 与 confirmed 共用一个绿灯 |

颜色仅辅助，使用图标、文字、形状和计数；图例常驻，筛选显示当前范围与隐藏数量。绿色只用于当前有效、满足其契约的具体主张；lapsed 不维持无条件绿色。默认保留全部状态分桶，未决提醒常驻但不强迫所有节点展开。Run 不提供单一健康灯，也不提供安全百分比。

## 4. 详情与证据阅读

固定阅读顺序：问题与实际目标 → 前提门/采用成员及评估版本 → 假设与方法摘要 → 调用序列 → 证据/支持与反例 → 六轴状态与限制 → 复审区。授权、预算、租约、取消及旧调用核对另设硬约束区块。

调用显示脱敏实际命令/规范化参数、cwd、工具/脚本与环境版本、实际实例、起止/持续时间、退出状态、用途与执行关系、stdout/stderr 及证据链接。说明标为模型解释或计划摘要，不展示内部思维链，不用说明替代实际命令。长输出按归档片段读取，展示来源、偏移、完整/截断/脱敏/缺失、hash 与引用范围。

任何图节点、Finding、复审意见和报告的证据引用都带四维完整性限制。结论到证据片段一跳可达，反例可回跳所反驳的主张版本和条件。hash 相同的不同调用保留采集身份；共享证据显式说明同一来源。主张类别未登记、验证要求未明确、证据不足与无法判定分别显示。

## 5. 业务操作与人工复审

本浏览器保存缩放、拖拽、展开、筛选、固定坐标与选中；这些不进入模型上下文、覆盖或预算。Run 共享视图书签走版本化业务接口，但不能触发规划、模型请求或目标执行。

暂停研究项/Run、取消、补充条件、请求补证、调整业务标记或关系均走受信业务接口，携带实际对象版本；提交期间显示正在提交。版本冲突展示所见版本与最新事实，由操作员重新选择，不静默重发。查看历史/冻结图时动作须先核对当前版本，禁止按旧画布派发。恢复展示是否仍有未知调用、停止事实、范围/期限/预算及将继续的工作。

人工可确认、退回或标为未决，保存决定、依据、输入版本与 Web 会话来源；不能编辑原始证据。退回可提出具体补证需求，目标执行仍经授权和预算检查。修改影响或 CVSS 指标需有依据、重新计算与复审，不提供任意改分入库按钮。共享密钥的会话来源不认定自然人身份。

ReviewQueue 分等级展示 requested/in_review/on_hold、已完成意见、独立结果与产出方的分歧、SLA 升级、待处理数/最久等待/背压。超 SLA 不自动确认；人审等待可与自动阶段已结束并列。补证需求指定缺的证据/关系及预期验证，不凭补证任务完成标为补齐。

## 6. 同步、覆盖与异常

| 情形 | 界面行为 |
| --- | --- |
| 初始快照/邻域加载 | 显示加载与范围；按额度展开，不以当前加载节点冒称总量 |
| 投影落后 | “已投影 X / 已发布 Y”、更新时间、补拉入口；明确其不表示执行停止 |
| 断线/鉴权失效 | 断线横幅与状态待同步；同版本游标续拉或缺口重载；会话失效按认证流程处理 |
| 截断/查询额度耗尽 | 截断原因、已返回/逻辑展开量、深度与水位；提供缩小范围/快照入口，不无限重试 |
| 版本冲突 | 展示最新业务版本，清楚说明未提交的操作；不将乐观画布状态冒作成功 |
| 排队/容量背压 | 等待类别、等待时长、相关资源、最后已知占用者；停止未确认明确标记 |
| 估计不足 | 顺位仅是调度快照参考；ETA 依据不足显示无法估计，不造固定开始时间 |
| 输入失效/证据缺失 | 冻结历史可读与当前不可核验并列，退出原因与重审需求可查 |

覆盖缺口仅从已登记范围/入口/问题及来源版本派生，必须可解释为什么登记。比例注明“在版本 V 登记的 N 项研究问题中”；`total_basis` 未知且分母未知时比例也未知，不用估计比例填满进度环。图负责研究关系与叙事；授权截止、预算、总费用和运行控制在专门面板，局部成本可在详情链接。

拓扑与增量布局保持已有位置，全图重排由显式动作触发。SVG 用于小图和静态导出，Canvas 为交互主路径；WebGL 待实测必要才引入。按需邻域、LRU 卸载、时间线虚拟滚动、标签降密度；跨 Run 并排比较各自水位，近似时间对齐标启发式，不能生成 EvidenceBinding。

提供键盘选择/展开、可访问名称、列表替代视图、可读焦点、非颜色编码和缩放后的文字阅读方式。窄屏允许图与详情切换，但全局未决/未知/隔离摘要持续可见。徽章、色值、尺寸、断点与具体布局参数留视觉规格及实测，不影响状态语义。

## 7. 验收与场景

1. 方法不适用或主张被反驳 → 转向 → 新证据 → 独立/人工复审：区别 ended(method_inapplicable) 与 refuted；旧尝试保留，不把服务标安全；server 最小实证自动执行后待最终人审。
2. A 目标等访问条件、B 目标继续：all_of/any_of 三值正确显示，受阻不占物理额度；补充条件触发版本化重评，独立分支不被阻断。
3. 运行重启有未知调用：恢复同一 Run，显示旧实例/调用、结果未知与停止事实，不从头扫描、不盲目重试；只有停止确认后释放物理额度，结果核对仍独立可见。
4. 冻结后必要证据过期：冻结清单不变，历史判定和当前 lapsed/准入退出并列；不自动开启研究，原始材料保留至保存期限或明确固定。

成对验证：颜色移除后状态仍可辨识；本地偏好清空后相同范围业务语义一致；确认等级不足不成立；跨授权展开不执行；投影滞后仍按最新业务版本校验；无精确分母无覆盖比例；每个结论/反例一跳到绑定片段；四维限制随引用；队列堆积不静默丢弃；窄屏/键盘流程可达。容量、长时与对照负载验收见 [0003 §9](./0003-agent-research.md#9-图语义与调度的成对验收)。

P2-F 可使用固定业务记录独立验证骨架，不等待完整 Agent 闭环；A1/A4 术语固定后再接动态文案。当前前端仅有基础 Run 配置和调用/证据/时间线控制台，不把本规格的图、复审队列或冻结页面标成已交付。
